## 模板代码分析
当我们学习一门新的编程语言时最开始往往都是以该语言的起手式代码开始的，例如我们学习C语言时对应的起手式代码就是：
```c
#include <stdio.h>

int main(void)
{
    printf("Hello, World!\n");
    return 0;
}
```
`Python`的起手式代码就是：
```python
def main() -> None:
    print("Hello, World!")


if __name__ == "__main__":
    main()
```
起手式代码是后续所有高阶代码的基础，学习他们能够让我们快速认识一门新的语言，帮助我们建立自信，下面展示的就是汇编语言的起手式代码
```nasm
; 模板代码

DATA SEGMENT

    RESULT DW 0

DATA ENDS
  

STACK SEGMENT STACK

    DB 128 DUP(?)

STACK ENDS

CODE SEGMENT

    ASSUME CS:CODE, DS:DATA, SS:STACK

START:

    MOV AX, DATA
    MOV DS, AX

  
    ; TODO: put your instructions here.

    ; Keep the result in AX or RESULT when debugging.


    MOV AX, 4C00H

    INT 21H

CODE ENDS

END START
```
乍一看发现汇编语言的起手式代码比我们之前学过的高级语言的起手式代码都要复杂，但是实际上它们都是有着固定的格式的，汇编语言代码同样可以进行拆分
