### 1. 终端分屏与面板管理 (Terminals)

这是 Tilix 最核心的功能，用于在同一个窗口内切分出多个终端。

| **快捷键**             | **功能描述**                  |
| ------------------- | ------------------------- |
| `Ctrl + Alt + R`    | **向右拆分**终端 (垂直分屏 Right)   |
| `Ctrl + Alt + D`    | **向下拆分**终端 (水平分屏 Down)    |
| `Alt + 方向键`         | 在不同的分屏面板之间**移动焦点**        |
| `Alt + 数字键`         | 切换到当前会话中指定编号的分屏面板         |
| `Alt + Shift + 方向键` | **调整**当前终端面板的宽高**大小**     |
| `Ctrl + Shift + X`  | **最大化**当前选中的面板 (再次按下恢复平铺) |
| `Ctrl + Shift + W`  | **关闭**当前选中的终端面板           |

### 2. 会话管理 (Sessions)

会话（Session）相当于传统终端中的“标签页（Tab）”，每个会话内部可以包含多个上述的分屏终端。

| **快捷键**            | **功能描述**            |
| ------------------ | ------------------- |
| `Ctrl + Shift + T` | **新建会话** (相当于新建标签页) |
| `Ctrl + PageUp`    | 切换到**上一个**会话        |
| `Ctrl + PageDown`  | 切换到**下一个**会话        |
| `F12`              | 展开/折叠右侧的会话管理缩略图侧边栏  |

### 3. 常规与文本操作 (General)

与大多数 GNOME 终端保持一致的基础操作。

| **快捷键**            | **功能描述**     |
| ------------------ | ------------ |
| `Ctrl + Shift + C` | **复制**选中的文本  |
| `Ctrl + Shift + V` | **粘贴**文本     |
| `Ctrl + Shift + F` | 在终端中**查找**文本 |
| `Ctrl + +`         | **放大**字体     |
| `Ctrl + -`         | **缩小**字体     |
| `Ctrl + 0`         | 恢复**默认**字体大小 |

> **进阶提示：**
> 
>   
> 
> - **修改快捷键：** 如果你觉得默认快捷键不顺手，可以在 Tilix 的右上角菜单点击 **“首选项 (Preferences)”** -> **“快捷键 (Shortcuts)”** 中进行完全自定义。
>     
>       
>     
> - **Quake (下拉式) 模式：** 很多用户喜欢将 Tilix 当作按键呼出的下拉式终端使用（通过运行 `tilix --quake`）。这通常需要你在 Linux 桌面的系统设置中，手动绑定一个全局快捷键（比如 `F11` 或 `Ctrl + ~`）来执行这个命令。
