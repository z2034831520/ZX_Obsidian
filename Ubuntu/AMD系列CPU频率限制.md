## 引言
我的笔记本电脑搭载的`CPU`型号是`AMD`的`8945HX`
![](assets/AMD系列CPU频率限制/file-20260822082431661.png)
这款`CPU`的性能强劲，但同时发热量也会比较大，这几乎是所有`HX`系列`CPU`的通病。厂商为了能有更好的跑分通常会想办法将功耗墙拉的很高，且笔记本的散热模组受限于体积问题很难压得住这么大的发热量

且现在的厂商为了能够保证电脑的使用流畅度都会选择为`CPU`设置激进的瞬时功耗，`CPU`的工作逻辑就变成了：“一旦有新的任务出现我就会用最暴力的性能在短时间内将这个人物处理掉，然后再快速回到低功耗待机状态”。这种调度策略就会导致当你在使用电脑的时候会出现`CPU`短期内温度迅速攀升，然后风扇狂转，短时间内温度又会降回去。这及其影响我们的日常使用体验，面对这种情况，我们通常会选择限制`CPU`的最高睿频来解决问题。在`windows`下只需要更改电源计划里的`CPU`最高频率即可，接下来我就会介绍一下如何在`Ubuntu`中解决这个问题

## 实操
### 确定频率上限
首先我们需要确定一件事：合理的最高睿频是多少？这个我们需要自己手动进行调整确认，确认的方法很简单，如果之前你在`Windows`下也进行过对应的`CPU`睿频限制操作，那么你可以直接把`Windows`平台下的参数照搬过来。如果你之前没有这么做过或者你想要根据新的操作系统定制一套新的参数那么可以自己手动调整，调整的命令如下：
```bash
sudo cpupower frequency-set --max 4.8GHz
```
后面的`4.8GHz`是对应的最高频率限制，可以自己手动修改对应的参数，修改之后可以尝试同时打开多个软件，观察一下`CPU`的温度变化和风扇的转速变化
