### 使用命令行工具 `wmctrl`

1. **安装工具：** 打开终端，运行以下命令安装：
    
    Bash
    
    ```
    sudo apt install wmctrl
    ```
    
2. **置顶指定窗口：** 假设你要置顶一个名为 "Firefox" 的窗口，运行：
    
    Bash
    
    ```
    wmctrl -r "Firefox" -b add,above
    ```
    
    _(注意：`"Firefox"` 替换为目标窗口标题栏上实际显示的名称，支持模糊匹配。)_
    
3. **取消置顶：**
    
    Bash
    
    ```
    wmctrl -r "Firefox" -b remove,above
    ```
    

> **额外提示：** 如果你是在结合之前提到的 **Tilix** 终端使用，Tilix 本身支持 **Quake（下拉式）模式**。如果你只是希望终端能随时悬浮在所有窗口最上方并随时呼出隐藏，直接运行 `tilix --quake` 并为其绑定一个全局快捷键（如 `F12`），体验会比单纯的窗口置顶好得多。
