## 简介
环形缓冲区是一种通用的数据结构，其核心思想是：将一块固定大小的数组，逻辑上首尾相连成环，用写指针和读指针循环复用空间，实现`O(1)`的先进先出(`FIFO`)读写

`freertos`底层通信机制如队列就是基于环形缓冲区实现的，主要用于中断和任务之间的通信，在实际的使用场景中，中断往往会被快速写入缓冲区，然后通知对应任务，任务被唤醒之后就会开始负责读取和处理数据

## 构成
环形缓冲区的构成较为简单，主要是固定数组加上**读指针**(`tail`)和**写指针**(`head`)
```c
typedef struct
{
	uint8_t buffer[128];
	uint16_t head;
	uint16_t tail;
}Buffer_t
```

在运作过程中独立移动，发生写操作时写指针就会指向下一个元素
```c
head = head->next
```
发生读操作时读指针也会自动指向下一个元素
```c
tail = tail->next
```

当读写指针指向同一个元素时表明当前数组已经空了
```c
head == tail
```
当写指针指向元素的下一个元素是读指针指向的元素，表明当前缓冲区已满
```c
(head + 1) % size = tail
```
