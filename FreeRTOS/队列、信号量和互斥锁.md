# 队列、信号量和互斥锁

## 如何选择

| 机制 | 主要用途 | 是否携带数据 |
|---|---|---|
| 队列 | 任务或中断之间传递消息 | 是，按值复制 |
| 二值信号量 | 事件同步 | 否 |
| 计数信号量 | 资源计数或累计事件 | 只有计数 |
| 互斥锁 | 保护共享资源 | 否 |

## 队列

`xQueueCreate()` 指定元素数量和单个元素大小。发送与接收可设置阻塞时间；队列满时发送者可阻塞，队列空时接收者可阻塞。

```c
QueueHandle_t queue = xQueueCreate(8, sizeof(uint16_t));
xQueueSend(queue, &value, pdMS_TO_TICKS(10));
xQueueReceive(queue, &value, portMAX_DELAY);
```

队列复制的是数据本身。传递指针时必须保证被指向对象在接收方使用期间仍然有效。

## 信号量与互斥锁

二值信号量适合“中断通知任务”等事件同步；计数信号量适合表示多个相同资源。互斥锁用于共享资源，并提供优先级继承以缓解优先级反转。互斥锁的获取与释放应由同一任务完成，不能替代中断同步信号量。

## ISR 使用边界

中断中只能使用以 `FromISR` 结尾的 API，例如 `xQueueSendFromISR()` 和 `xSemaphoreGiveFromISR()`，并根据返回的唤醒标志请求一次上下文切换。

## 常见问题

- 用全局变量加标志位代替同步，产生竞态条件。
- 在队列中传递失效的局部变量指针。
- 用二值信号量保护共享资源，失去优先级继承。
- 持有互斥锁期间进行长时间阻塞。
