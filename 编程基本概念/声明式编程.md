# 简介
声明式编程并不是一种特定的编程语言，而是一种编程范式或编程思想，它的核心思想为：告诉机器我想要什么，而不是我想要怎么做

# 特性
在声明式编程中，开发者扮演的是甲方的角色，我不需要具体的去实现每一处的底层逻辑，而是通过定义规则、关系以及最终的期望状态来调用系统中已经实现了的方法

# 优势
这种编程方式有两个好处：
- 可读性提高：写代码就像是在写需求文档，且大部分系统已经实现的内置方法都见名知意，英语能力稍微好一点的就能够在不借助注释的情况下直接推理出程序的意图
- 代码健壮性高：通过调用系统的内置函数，我们就不需要自己去处理边界条件、内存指针以及索引溢出等底层操作，出现报错的概率就大幅降低
