# 简介
命令式编程是最古老、最基础、也是最接近硬件运行本质的编程范式
如果说[声明式编程](声明式编程.md)是给下属下达最终目标的CEO，那么命令式编程就是一个无微不至的微操大师

# 思想内核
命令式编程的思维模型，完美映射了现代计算机的基础架构——冯诺依曼体系，在该体系下计算机的底层本质只有两件事：内存（存取状态）和CPU（执行指令）。命令式编程的代码就是对这两件事的直接翻译：
1. 申请一块内存（定义变量）
2. 告诉CPU一步步执行操作
3. 不断修改这块内存里的值，知道得到想要的结果
在命令式编程中，、你就是CPU的独裁者，你不需要底层去猜测你的意图，你的代码本身就是真理

# 组成部分
任何纯粹的命令式语言都离不开一下三个核心元素
## 可变状态
命令式的编程环境下系统的状态式随着时间变化的，我们可以通过定义变量，并在程序运行过程中不断的覆盖重写这些变量来进行逻辑的推进
- 表现：`let i = 0; i++; temp = a; a = b; b = temp;`
- 本质：直接操控内存地址中的值

## 控制流
在命令式编程中我们拥有绝对的权力，通过精确的条件语句和循环语句，指挥程序在什么情况下向左走、向右走、或者原地等待

- 本质：对应CPU的跳转指令

## 指令排序
代码的上下文高度依赖执行顺序，第三行代码执行的前提往往是第二行代码已经正确的修改了某个状态，一旦顺序出现问题或者前面的逻辑没有正确执行，那么整个逻辑就会崩塌

# 优势
## 性能透明
代码怎么写，程序就怎么运行，没有不可控的框架开销
## 调试直观
当程序出现错误时，可以通过Debugger进行单步调试，最终得到错误位置和错误原因
