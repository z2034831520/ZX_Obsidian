# 常见调试工具和故障定位方法

## 工具与证据

| 工具 | 适合观察 |
|---|---|
| ST-LINK、J-Link | 寄存器、变量、断点、调用栈、Fault 状态 |
| 串口日志、SWO | 程序运行轨迹和关键状态 |
| 示波器 | 模拟电压、时钟质量、边沿、纹波和时序 |
| 逻辑分析仪 | UART、SPI、I2C、PWM 等数字协议 |
| 万用表 | 电源、短路、静态电平和连通性 |
| 编译 Map 文件 | Flash/RAM 占用、符号地址和链接布局 |

## 推荐定位顺序

1. **供电与复位**：电压、NRST、BOOT 引脚是否正常。
2. **时钟**：系统是否进入预期时钟源，外部晶振是否起振。
3. **程序入口**：复位向量、启动文件和 `main()` 是否到达。
4. **外设配置**：时钟、引脚复用、寄存器和中断链路。
5. **真实信号**：用示波器或逻辑分析仪确认引脚是否产生预期波形。
6. **软件状态**：检查返回值、错误标志、Fault 寄存器和任务状态。
7. **最小化复现**：关闭无关模块，只保留故障链路。

## HardFault 关注点

保存堆栈中的 PC、LR、xPSR，以及 SCB 的 CFSR、HFSR、BFAR 和 MMFAR。根据故障地址回到 Map 文件或反汇编定位，而不是只在 HardFault_Handler 中停住。

## 常见误区

- 只看源码，不测量真实引脚。
- 一次修改多个变量，无法判断哪项生效。
- 忽略 HAL 返回值和外设错误标志。
- 把优化、缓存或竞态问题误判为“硬件偶发故障”。
