# 定时器、PWM 与输入捕获

## 定时器基本关系

计数频率通常由定时器输入时钟和预分频器决定：

```text
计数频率 = 定时器时钟 / (PSC + 1)
更新频率 = 计数频率 / (ARR + 1)
```

STM32 某些系列在 APB 预分频不为 1 时，定时器时钟可能是 APB 时钟的两倍，必须查看时钟树和参考手册。

## PWM

PWM 周期由 ARR 决定，占空比由 CCR 决定。边沿对齐模式下可近似理解为：

```text
占空比 = CCR / (ARR + 1)
```

配置 PWM 时同时检查通道复用、极性、输出使能；高级定时器还可能需要主输出使能。

## 输入捕获

输入边沿到来时，硬件把当前计数值锁存到 CCR。相邻捕获值之差可用于计算周期或频率；同时捕获上升沿与下降沿可计算高电平宽度和占空比。必须处理计数器溢出和输入噪声。

## 常见问题

- 忽略 APB 到定时器的时钟倍频关系。
- PSC、ARR 计算少了加一。
- 只初始化通道但没有启动 PWM 或捕获。
- 捕获值溢出后直接相减。
- 高速输入下在中断里处理过慢，造成丢边沿。
