## 逻辑通信
传输层的协议未运行在不同主机上的应用程序提供了逻辑通信功能

### 端口
端口号长度未16位比特，取值范围是`0~65535`
端口号分为服务端口号和客户端端口号，其中服务端端口号又分为知名端口号(`0~1023`)和注册端口号(`1024~49151`)

常见的知名端口号为：


| 端口    | 协议      | 用途     |
| ----- | ------- | ------ |
| 20、21 | `FTP`   | 文件传输   |
| 22    | `SSH`   | 远程登录   |
| 25    | `SMTP`  | 电子邮件   |
| 80    | `HTTP`  | 万维网    |
| 110   | `POP-3` | 访问远程邮件 |
| 143   | `IMAP`  | 访问远程邮件 |
| 443   | `HTTPS` | 安全的Web |
| 543   | `RTSP`  | 媒体播放控制 |
| 631   | `IPP`   | 打印共享   |
