## 简介
这里主要展示一下数字小键盘中每一个键位和对应编号之间的映射关系

## 映射关系
```txt
键盘顶部（屏幕、旋钮方向）

┌──────┬──────┬───────────────┐
│  K1  │  K2  │     空位       │
├──────┴──────┼──────┬────────┤
│   K3 横向键  │  K4  │   K5   │
├──────┬──────┼──────┼────────┤
│  K6  │  K7  │  K8  │   K9   │
├──────┼──────┼──────┼────────┤
│ K10  │ K11  │ K12  │        │
├──────┼──────┼──────┤  K16   │
│ K13  │ K14  │ K15  │ 纵向键  │
└──────┴──────┴──────┴────────┘

键盘底部
```

功能映射

| 编号  | 当前功能              |
| --- | ----------------- |
| K1  | 打开资源管理器 `Win+E`   |
| K2  | 下一曲               |
| K3  | 打开 Gemini 网页      |
| K4  | 增大音量              |
| K5  | 减小音量              |
| K6  | 字母 A              |
| K7  | 字母 B              |
| K8  | 字母 C              |
| K9  | 静音                |
| K10 | 未配置               |
| K11 | 未配置               |
| K12 | 未配置               |
| K13 | 未配置               |
| K14 | 数字 0              |
| K15 | `Ctrl+Alt+Delete` |
| K16 | 播放/暂停             |
