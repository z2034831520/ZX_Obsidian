### 内容介绍
核心原则：表中的每一列都是不可分割的最小数据单元，不能包含集合、数组或多个值

### 解决问题
如果某个字段里塞进了多个数据，导致无法对单一数据进行高效查询或统计

### 示例
**改造前（不符合 1NF）：**

| **学生 ID** | **姓名** | **选修课程**    |
| --------- | ------ | ----------- |
| 101       | 张三     | 计算机网络, 操作系统 |
| 102       | 李四     | 数据库原理       |
分析：选修课程字段包含了多个值，违反了原子性，如果想要查询“选修了操作系统的学生”，需要使用低效的模糊匹配

**改造后（符合 1NF）：**

| **学生 ID** | **姓名** | **选修课程** |
| --------- | ------ | -------- |
| 101       | 张三     | 计算机网络    |
| 101       | 张三     | 操作系统     |
| 102       | 李四     | 数据库原理    |
