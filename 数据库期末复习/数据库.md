## 定义
数据库是长期存储在计算机内、有组织的、可共享的大量数据的集合

## 特点

| 特征        | 含义                        |
| --------- | ------------------------- |
| 永久存储      | 长期保存在外存上                  |
| 有组织       | 数据是按照一定的数据模型组织起来的，不是随便堆放的 |
| 可共享       | 一个数据库可以被多个用户以及多个程序使用      |
| 冗余度低，独立性高 | 数据冗余度低，独立于应用程序            |
它不仅仅是数据的简单堆砌，而是按照一定的数据模型（如关系模型）组织、描述和存储的，它可以看作是一个高级的文件柜，里面按照分类和预先设定好的结构存储着[数据](数据.md)，是**数据的容器**
