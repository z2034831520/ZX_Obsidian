## 简介
本文主要介绍一下如何使用分治法的思想来解决斐波那契数列的求和问题

## 斐波那契数列
斐波那契数列的规律想必大家都耳熟能详了，斐波那契数列中每一个数都是由前面两个数据相加得到的，第一个和第二个数据由于没有足够的前置数据，所以默认值都是1，了解了规律之后题目往往会给我们一个数据，然后让我们计算该位数据的值。在刚接触到这个问题的时候，我们往往会采用递归的方式来解决此问题，对应的代码也非常的浅显易懂
下面是一段最简单的递归函数求解斐波那契数列的代码
```C++
// 输入 n >= 0，返回第 n 个斐波那契数
int fibonacci(int n) 
{
    if (n <= 1) 
    {
        return n;
    }
    return fibonacci(n - 1) + fibonacci(n - 2);
}
```
上述函数的缺点是时间复杂度较高，且重复的部分会被反复计算，随着输入数据的不断增大，栈递归的深度会越来越深，有发生栈溢出的风险

所以接下来我就介绍一种更加高效的方法来解决这个问题

## 矩阵
让我们回想一下，递归为什么会这么慢？最简单的递归函数完全按照$F(k) = F(k - 1) + F(k - 2) \quad (k \ge 3)$进行编写，但是这样一来程序会反复计算相同的项，如果我们能够将**从相邻两项走到下一项**写成一个固定的运算，那么连续走很多步，就可以变成这个运算的幂。那有没有这种计算的方法呢？当然是有的，我们可以借助矩阵来记录每一步的变化
