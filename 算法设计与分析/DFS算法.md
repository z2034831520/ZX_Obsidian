## 简介
`DFS`算法，全称为(`Depth-First Search`，简称`DFS`)即深度优先搜索是一种用于遍历树、图或枚举状态的经典算法，我们可以将其理解为走迷宫的时候，不撞南墙不回头，每次遇到岔路口的时候，选择其中的一条，一直向深处走，知道彻底走不通或者到达终点，才退回上一个岔路口，换另一条没有走过的路

## 核心机制
深度优先搜索算法的核心运行机制为递归于回溯，DFS通常通过函数递归来实现，整个搜索过程中，像在一颗倒置的决策树上游走，包含两个反复交替的动作：
- 向深处递进（递归调用）：在当前状态下做出一个选择，带着更新后的状态进入下一层函数，相当于沿着树枝往叶子节点走
- 回退上一步（退回上一步）：当某一层到达边界或所有分支都探索完毕之后，函数执行完毕并返回上一层，撤销刚才做出的选择，换下一个分支继续尝试

## 编写要领
在编写使用到DFS的程序时我们需要想明白下面四件事：
- 设计状态参数：思考需要哪些变量才能描述当前走到了哪里（例如：在”选数“题目中，需要知道当前起始下标`start`、已选个数`count`和当前累加和`sum`
- 确定终止条件：规定什么情况下停止搜索（例如`count == k`选够了数，或者下标越界）拿到结果后立刻`return`，防止无限递归导致栈溢出
- 遍历可选分支：在当前层通过循环或条件分支，枚举下一步所有合法的选择（例如从`start`到`n`枚举到下一个要选得数，或在迷宫中尝试上、下、左、右四个方向）
- 标记状态与恢复现场：如果使用了全局数组或者应用记录路径，在递归调用返回后必须将其还原，以免干扰后续分支；若直接通过函数参数传值，返回上一层时变量会自动保持原值，无需手动还原

## 标准的代码模板
深度优先遍历的标准模板为：
```C++
void dfs(当前状态参数) {
    // 1. 终止条件（递归出口）
    if (到达目标状态 或 越界) {
        记录答案或更新结果;
        return;
    }

    // 2. 剪枝（可选：提前淘汰不可能成功的分支）
    if (当前状态已经不可能达成目标) {
        return;
    }

    // 3. 遍历当前所有可能的选择
    for (枚举下一步的每个合法分支 i) {
        if (分支 i 未被访问 且 满足限制条件) {
            vis[i] = true;          // 标记现场（做出选择）
            dfs(更新后的状态参数);    // 递归进入下一层
            vis[i] = false;         // 恢复现场（回溯撤销选择）
        }
    }
}
```
