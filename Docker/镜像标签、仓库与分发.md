# 镜像标签、仓库与分发

镜像引用通常为：

```text
[registry/][namespace/]repository[:tag][@digest]
```

Tag 是可变别名，`latest` 也只是普通标签，不代表自动选择最新安全版本。Digest 指向确定内容，适合要求可复现的部署。

```bash
docker build -t registry.example.com/team/app:1.4.0 .
docker push registry.example.com/team/app:1.4.0
docker pull registry.example.com/team/app@sha256:...
```

推荐同时维护语义化版本标签、提交哈希标签和发布渠道标签。生产部署最好记录或锁定 digest。推送前确认登录的仓库、命名空间和权限，避免把包含密钥或调试文件的镜像公开发布。

分发流程应包含构建、测试、漏洞扫描、生成 SBOM、签名或来源证明、推送和部署验证。清理标签不一定立即释放仓库存储，因为多个标签可能共享相同层。
