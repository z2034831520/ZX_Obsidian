# 容器生命周期和常用命令

镜像是只读模板，容器是镜像加可写层和运行配置形成的实例。容器的主进程 PID 1 退出后，容器即停止。

```bash
docker create --name app image
docker start app
docker run -d --name app image
docker ps -a
docker logs -f app
docker exec -it app sh
docker stop app
docker restart app
docker rm app
docker inspect app
```

`docker run` 相当于 create 加 start；再次执行会创建新容器，而不是更新旧容器。持久数据应放在卷或外部存储中，不能依赖容器可写层。

停止时 Docker 先向主进程发送停止信号，超过宽限期后强制结束。应用应正确处理信号并完成资源释放。自动恢复可通过 restart policy 配置，但持续崩溃的容器仍需查看退出码和日志，而不是只依赖重启。

## 常见问题

- 把镜像、容器和进程混为一谈。
- 在运行容器内手工修改后没有形成可复现构建。
- 删除容器前未确认数据是否挂载。
- 主进程把信号吞掉，导致无法优雅退出。
