# 端口映射、卷挂载和环境变量

## 端口

`EXPOSE` 只描述容器监听端口；真正发布到宿主机使用 `-p`：

```bash
docker run -p 127.0.0.1:8080:80 nginx
```

省略宿主地址可能监听所有网卡。服务自身还必须监听容器内的 `0.0.0.0`，只监听 `127.0.0.1` 时通常无法从容器外访问。

## 存储

- **命名卷**：由 Docker 管理，适合数据库和持久数据。
- **绑定挂载**：直接映射宿主路径，适合开发源码和配置。
- **tmpfs**：只存在于内存，适合临时敏感数据。

```bash
docker run --mount type=volume,src=dbdata,dst=/var/lib/app image
docker run --mount type=bind,src="$PWD",dst=/app,readonly image
```

删除容器通常不会自动删除命名卷。备份时不仅复制数据，还应考虑数据库一致性。

## 环境变量

环境变量适合非敏感配置；密钥应使用 Secret 管理机制或受控文件挂载。不要把密钥写进 Dockerfile，因为镜像历史可能保留它。

## 常见问题

- Windows 路径和 PowerShell 引号处理错误。
- 绑定挂载覆盖了镜像中原有目录。
- 端口已被宿主进程占用。
- 误以为环境变量对已经创建的容器会自动更新。
