# 构建缓存与多阶段构建

Docker 按层判断缓存是否可复用。某一步输入发生变化时，该步骤及其后的层通常需要重新构建。因此应把变化少的依赖文件先复制和安装，把经常变化的源码放在后面。

```dockerfile
FROM node:22 AS build
WORKDIR /src
COPY package*.json ./
RUN npm ci
COPY . .
RUN npm run build

FROM nginx:alpine
COPY --from=build /src/dist /usr/share/nginx/html
```

多阶段构建用多个 `FROM` 隔离编译环境和运行环境，最终镜像只保留运行所需产物，可减少体积和攻击面。阶段应命名，避免依赖数字序号。

BuildKit 支持缓存挂载和 Secret 挂载。密钥不应通过 `ARG`、`ENV` 或复制文件的方式写入镜像层。排查缓存时使用构建日志确认命中情况；`--no-cache` 适合验证问题，不应作为日常默认。
