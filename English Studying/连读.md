## 简介
在英语口语中连读是一个非常重要的发音技巧，掌握连读可以让我们更加自然的进行日常对话，主要是避免阅读时的生硬感

## 连读场景
英语口语中的连读并不是我们想连读就连读的，我们需要需要知道什么时候应该进行连读，什么时候不应该进行连读，接下来我会介绍一下在英语口语中需要进行连读的场景

### 辅音结束元音开始
这是最直观的连读情况，单词拼写和发音完全对应

| **原词组**        | **连读后的听感（像一个新词）** | **拼读原理解析**                    |
| -------------- | ----------------- | ----------------------------- |
| **Hold on**    | Hol-**don**       | /d/ + /ɒ/ 拼成 /dɒ/             |
| **Not at all** | No-**ta-tall**    | /t/ + /æ/，/t/ + /ɔː/ （连续两处连读） |
| **Stand up**   | Stan-**dup**      | /d/ + /ʌ/ 拼成 /dʌ/             |
| **Turn it on** | Tur-**ni-ton**    | /n/ + /ɪ/，/t/ + /ɒ/ （连续两处连读）  |
