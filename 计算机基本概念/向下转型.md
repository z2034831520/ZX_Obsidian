## 简介

 向下转型就是将父类引用恢复为子类类型，在进行此操作时需要进行显示强制转换

堆内存中创建好的对象客观类型并不会改变，向下转型改变的只是占内存中的“引用变量”的类型

## 作用
我们在实际开发中往往并不知道方法中接收到的对象是什么类型，在Java中重写equal方法时方法的参数类型必须是共有父类`Object`，这样才能接收任意类型的对比对象，因此在方法中我们需要使用到向下转型

```java
public class Student {
    private String id;

    // 重写 equals 方法，用于判断两个 Student 是否是同一个人（学号相同）
    @Override
    public boolean equals(Object obj) {
        // 1. 极端情况判断：如果地址一样，肯定是同一个对象
        if (this == obj) return true;
        
        // 2. 血统安检：传进来的 obj 到底是不是 Student？
        // 如果 obj 是 null，或者根本不是 Student 类，直接返回 false
        if (!(obj instanceof Student)) {
            return false;
        }
        
        // 3. 向下转型（关键步）：
        // 因为 obj 的编译类型是 Object，我们无法调用 obj.id。
        // 既然安检已经通过，我们就可以安全地把它强转为 Student。
        Student otherStudent = (Student) obj;
        
        // 4. 比较子类特有的属性
        return this.id.equals(otherStudent.id);
    }
}
```

在进行向下转型时必须确保向下转型的对象是当前对象的子类，否则就会引发报错，在Java中我们可以使用`instanceof`方法进行检测，当结果正确时才进行向下转型
