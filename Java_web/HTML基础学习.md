## 起手式
在`Vscode`中安装了对应的插件之后即可进行代码的编写
![](assets/HTML基础学习/file-20260903193252319.png)
`HTML`语言的起手式很简单，只需要在对应的`.html`文件中输出英文状态下的`!`即可弹出对应的提示，
![](assets/HTML基础学习/file-20260903193508942.png)然后我们按下键盘上的回车键即可自动补全`HTML`的起手式内容，具体内容如下
```html
<!DOCTYPE html>

<html lang="en">

<head>

    <meta charset="UTF-8">

    <meta name="viewport" content="width=device-width, initial-scale=1.0">

    <title>Document</title>

</head>

<body>

</body>

</html>
```
