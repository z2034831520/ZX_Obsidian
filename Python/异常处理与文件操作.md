# 异常处理与文件操作

## 异常结构

```python
try:
    value = int(text)
except ValueError as exc:
    print(f"格式错误: {exc}")
else:
    print("转换成功", value)
finally:
    cleanup()
```

`except` 只捕获预期异常，不要无条件吞掉所有异常。`else` 在没有异常时执行；`finally` 无论是否异常都会执行。需要保留原始异常上下文时可使用 `raise NewError(...) from exc`。

## 文件操作

使用 `with` 保证文件及时关闭，并明确文本编码：

```python
from pathlib import Path

path = Path("notes.txt")
with path.open("r", encoding="utf-8") as file:
    content = file.read()
```

文本模式处理字符串，二进制模式处理字节。Windows 与 Linux 的换行和路径表现可能不同，路径拼接优先使用 `pathlib`。

## 写入安全

覆盖写入前确认目标路径。重要数据可先写入同目录临时文件，刷新并关闭后再原子替换。批量处理时应记录成功与失败文件，避免一个异常让整体状态不可判断。

## 常见问题

- 使用 `except Exception: pass` 隐藏真实错误。
- 忘记指定编码。
- 在异常发生后继续使用未初始化变量。
- 拼接字符串构造路径。
- 覆盖源文件前没有备份或校验。
