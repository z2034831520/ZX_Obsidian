## f-string
`f-string`可以改变`print`函数输出时的输出内容，在输出字符串前面加上`f`或`F`即可直接在后续的字符串中的花括号内执行表达式或者变量嵌入，这种做法在代码编写中效率更高，同时也更加规范，因此在日常编写代码时都推荐在输出的字符串前面加上`f`
### 示例
假设我们想要输出指定内容，如设备温度，我们可以通过`f-string`的模式来实现输出指定内容
```python
print(f"设备温度为{temp_float + 1}")
```
在输出过程中我们还对温度变量进行了加一操作，最终的输出结果为
```bash
设备湿度为12.0
```
如果`f`删除之后输出结果则会变为
```bash
设备温度为{temp_float + 1}
```

## type获取变量类型
在`Python`中可以通过`type`函数来直接获取变量类型信息。如我们可以通过如下语句直接输出变量的类型信息
```python
print(f"设备编号对应变量类型为{type(ID_float)}")
```
输出结果为
```bash
设备编号对应变量类型为<class 'float'>
```
