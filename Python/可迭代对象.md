## 简介
在`Python`中可迭代对象的概念是在循环中被引出的，可迭代对象是指能够按顺序一个一个取出元素的对象

例如列表、元组、字符串、字典、集合、文件对象，通常都是可迭代对象

## 应用
在`Python`的`for`循环的基本语法格式如下：
```python
for <变量名> in 可迭代对象
	循环体内容
```
因此可迭代对象可以让`Python`能够以统一的方式处理多个数据

在`Python`中常见的可迭代对象如下：
```python
[1, 2, 3]                  # 列表
(1, 2, 3)                  # 元组
"hello"                    # 字符串
{"name": "Tom", "age": 20} # 字典
{1, 2, 3}                  # 集合
range(5)                   # range 对象
```
