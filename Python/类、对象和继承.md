# 类、对象和继承

## 类与对象

类定义数据和行为，对象是类的实例。`__init__` 负责初始化实例状态；实例方法的第一个参数通常写作 `self`。

```python
class Sensor:
    unit = "raw"

    def __init__(self, name):
        self.name = name

    def read(self):
        raise NotImplementedError
```

`unit` 是类属性，`self.name` 是实例属性。把可变对象作为类属性会让所有实例共享它，通常应改成实例属性。

## 继承

```python
class TemperatureSensor(Sensor):
    unit = "°C"

    def __init__(self, name, offset=0):
        super().__init__(name)
        self.offset = offset
```

子类可以覆盖父类方法，并通过 `super()` 复用父类实现。Python 支持多继承，方法查找顺序由 MRO 决定；复杂多继承应谨慎使用。

## 组合优先

“是一个”关系适合继承，“拥有一个”关系适合组合。将通信接口、传感器驱动或存储组件作为对象属性，通常比建立很深的继承层次更容易测试和替换。

## 常用特殊方法

- `__repr__`：开发和调试表示。
- `__str__`：用户可读文本。
- `__eq__`：相等比较。
- `__enter__/__exit__`：上下文管理。
- `__iter__`：迭代协议。
