## 简介
在编写程序时堆和栈是两个非常重要的概念，他们对于开发者来说是透明的，但是理解他们的作用可以帮助我们写出更加高效的代码，能够让我们理解代码的运行逻辑

Python中，变量名保存的是对象的引用；函数调用形成调用栈；对象的实际数据通常由Python在堆中管理

## 栈
### 主要功能
栈的主要功能是管理函数的调用过程
当函数被调用时，Python中需要记录的是
- 当前函数执行到了哪一行
- 函数的参数值
- 局部变量名
- 函数执行完之后应该回到哪里
这些运行信息可以看作一个**栈帧**，栈从数据结构的角度来看它有一个特性，即后进先出，函数每调用一层，就压入一层，函数结束，就退出一层。

### 例子
现在有如下示例代码
```python
def add(a, b):
    total = a + b
    return total

result = add(10, 20)
```
调用的过程可以理解为：
调用 add(10, 20)

调用栈顶部
```text
调用 add(10, 20)

调用栈顶部
┌──────────────────────┐
│ add 的栈帧            │
│ a -> 10              │
│ b -> 20              │
│ total -> 30          │
└──────────────────────┘
│ 外层程序的栈帧         │
│ result -> 等待接收结果 │
└──────────────────────┘
```
当add()执行完毕，它的栈帧退出，局部名字a, b, total不再可用

## 堆
### 主要功能
堆内存是用于动态分配内存的区域，Python中所有的对象（数字、字符串、列表、字典、类的实例等）都存放在这里



### 存储内容
实际的对象数据，例如`a = [1,2,3]`，变量名`a`存在栈里，而列表`[1,2,3]`这个实体对象存放在堆里

### 特点
堆空间相较于栈空间它的体积更大，但是在堆的读写速度相较于栈要更慢，

### 数据结构
从数据结构的角度来看堆空间的内容，堆通常是一个完全二叉树，最常见的应用是“优先队列”，它分为最小堆和最大堆：
- 最小堆：根节点的值是整个堆中最小的
- 最大堆：根节点的值是整个堆中最大的
