# 函数参数与作用域

## 参数形式

Python 支持位置参数、关键字参数、默认参数、仅限位置参数、仅限关键字参数，以及可变参数。

```python
def request(path, /, method="GET", *, timeout=3, **headers):
    ...
```

- `/` 前只能按位置传递。
- `*` 后只能按关键字传递。
- `*args` 收集额外位置参数。
- `**kwargs` 收集额外关键字参数。

## 可变默认参数

默认值在函数定义时只创建一次，因此不要把列表、字典等可变对象直接作为默认值。

```python
def add_item(item, items=None):
    if items is None:
        items = []
    items.append(item)
    return items
```

## 参数传递

Python 传递的是对象引用。函数可以修改传入的可变对象，但给局部变量重新绑定新对象不会改变调用方变量的绑定。

## LEGB 作用域

名称查找顺序是 Local、Enclosing、Global、Built-in。对外层函数变量重新赋值使用 `nonlocal`；对模块全局变量重新赋值使用 `global`。读取通常不需要声明。

## 常见问题

- 可变默认参数在多次调用之间共享状态。
- 实参与形参名称相同就误以为“按引用传递”。
- 用 `global` 共享大量状态，增加耦合。
- 内层函数赋值导致外层同名变量被遮蔽。
