# 字典、集合和元组

## 字典 dict

字典保存“键 → 值”映射。键必须可哈希，常见键包括字符串、数字和只含可哈希元素的元组。

```python
student = {"name": "Li", "score": 90}
student["score"] = 95
city = student.get("city", "unknown")
```

使用 `in` 判断键是否存在；遍历键值对使用 `for key, value in data.items()`。直接访问不存在的键会触发 `KeyError`，需要默认值时使用 `get()`。

## 集合 set

集合保存不重复的可哈希元素，适合成员判断、去重和集合运算。

```python
a = {1, 2, 3}
b = {3, 4}
print(a | b)  # 并集
print(a & b)  # 交集
print(a - b)  # 差集
```

空集合必须写成 `set()`，因为 `{}` 表示空字典。

## 元组 tuple

元组是不可变序列，适合表达固定结构、多个返回值和字典复合键。

```python
point = (10, 20)
x, y = point
```

元组本身不可修改，但其内部如果包含列表等可变对象，这些对象仍可被修改。

## 选择原则

- 按键查值：字典。
- 去重、快速成员判断、集合运算：集合。
- 固定顺序且不希望结构被改动：元组。
- 需要频繁按下标修改：列表。
