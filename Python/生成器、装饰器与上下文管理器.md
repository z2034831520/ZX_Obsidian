# 生成器、装饰器与上下文管理器

## 生成器

包含 `yield` 的函数返回生成器，按需产生数据，不必一次把所有结果放入内存。

```python
def read_valid(lines):
    for line in lines:
        line = line.strip()
        if line:
            yield line
```

生成器是一次性迭代器，遍历结束后不能自动重新开始。它适合流式文件、数据管道和大数据序列。

## 装饰器

装饰器接收函数并返回包装后的函数，可用于日志、计时、权限和缓存。

```python
from functools import wraps

def trace(func):
    @wraps(func)
    def wrapper(*args, **kwargs):
        print(func.__name__)
        return func(*args, **kwargs)
    return wrapper
```

`@wraps` 用于保留原函数名称和文档。装饰器不应偷偷改变返回值或异常语义。

## 上下文管理器

上下文管理器把“获取资源—使用—释放资源”封装在 `with` 中。类可实现 `__enter__` 和 `__exit__`，简单场景也可使用 `contextlib.contextmanager`。

```python
from contextlib import contextmanager

@contextmanager
def opened(path):
    file = open(path, encoding="utf-8")
    try:
        yield file
    finally:
        file.close()
```

## 关系

生成器解决按需生产数据，装饰器解决横切功能复用，上下文管理器解决资源生命周期。三者都依赖函数是一等对象和迭代协议等 Python 特性。
