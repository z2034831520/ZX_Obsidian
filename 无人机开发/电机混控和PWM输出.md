# 电机混控和 PWM 输出

## 混控作用

控制器产生总推力以及 Roll、Pitch、Yaw 三轴力矩需求，混控器根据机架几何、各电机位置和旋转方向分配到每个电机。

```text
总推力 + 三轴力矩 → 混控矩阵 → 各电机归一化输出 → ESC协议
```

四旋翼 X 架中，各电机对滚转和俯仰的贡献由位置决定，对偏航的贡献由旋转方向决定。电机编号与符号必须以当前机架定义为准，不能直接复制其他飞控的顺序。

## 输出协议

传统 PWM 使用脉宽表达油门，常见范围取决于电调标定和飞控配置。OneShot、MultiShot、DShot 等协议可提供更快更新或数字传输能力。使用何种协议取决于 MCU 定时器、ESC 和固件支持。

## 饱和处理

当混控结果超出允许范围时，需要限制或重新分配输出。简单裁剪可能导致某一姿态轴失去控制权，飞控通常会结合优先级和抗积分饱和策略处理。

## 上电检查

1. 拆桨。
2. 单独测试每一路输出对应的电机编号。
3. 确认旋转方向。
4. 确认最小、怠速和最大输出。
5. 小幅施加 Roll/Pitch/Yaw 指令，检查补偿方向。
6. 确认失控和断连时输出进入安全状态。

## 常见问题

- 电机编号、位置或旋向配置错误。
- PWM 定时器时钟计算错误。
- 电调未标定或最小油门设置不一致。
- 在输出饱和时仍持续积分。
- 带桨进行首次映射测试。
