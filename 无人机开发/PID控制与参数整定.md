# PID 控制与参数整定

## 基本作用

PID 根据误差生成控制量：

```text
u = Kp·e + Ki·∫e dt + Kd·de/dt
```

P 提供即时纠偏，过大会振荡；I 消除长期静差，过大会积分饱和；D 抑制快速变化，但会放大测量噪声。

## 飞控中的串级结构

多旋翼通常采用串级环：

```text
位置环 → 速度环 → 姿态角环 → 角速度环 → 电机输出
```

内环必须比外环更快。调参时先保证电机、传感器方向和控制符号正确，再从最内层角速度环向外调节。

## 安全整定流程

1. 固定机械结构，校准传感器和电调。
2. 降低输出限制，设置急停或断桨测试条件。
3. 先调 P：逐步提高至响应快但不过度振荡。
4. 增加 D 抑制振荡，并检查电机是否因噪声发热。
5. 增加 I 消除持续偏差，并设置积分限幅。
6. 逐步扩大飞行包线，记录设定值与实际响应。

每次只调整少量参数并保存日志。不同桨、电机、电池和机架都会改变所需增益。

## 常见问题

- 控制方向反了却继续调增益。
- 外环先于内环整定。
- D 项直接对噪声很大的误差求导。
- 没有积分限幅或解除饱和机制。
- 一次大幅修改多个参数。
