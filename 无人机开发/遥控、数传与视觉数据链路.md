# 遥控、数传与视觉数据链路

## 三类链路

- **遥控链路**：传递摇杆、开关和模式指令，强调低延迟与失联检测。
- **数传链路**：连接飞控与地面站，传递遥测、参数、日志和任务信息。
- **视觉链路**：传递目标位置、速度或控制偏差，数据率和时延通常更高。

## 接收处理链

```text
物理接口 → 字节接收 → 帧边界 → 长度/校验
→ 消息解析 → 时间戳与新鲜度检查 → 坐标转换
→ 合法范围限制 → 控制模块
```

任何外部控制数据都必须有超时机制，不能在断连后永久沿用最后一帧。视觉数据还要明确坐标系、单位、置信度、相机延迟和帧率。

## 带宽与调度

高频消息不一定都需要可靠重传。控制指令通常关注新鲜度，旧帧重传可能比丢弃更危险。日志、参数和升级数据则更关注完整性。应根据消息类型设置优先级和发送频率。

## 数据有效性

- 帧头、长度、序号和 CRC。
- 数值范围、NaN/Inf 和跳变检查。
- 来源、时间戳和超时。
- 模式是否允许外部控制。
- 坐标系和正负方向。
- 接收失败后的降级动作。

## 常见问题

- 在串口中断中完成整个协议解析。
- 没有帧序号，无法发现重复或丢帧。
- 视觉输出方向正确但单位或坐标系错误。
- 调试日志占满链路，阻塞控制数据。
