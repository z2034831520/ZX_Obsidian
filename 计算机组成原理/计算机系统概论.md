## 冯诺依曼体系结构
### 五大组成部分
运算器、控制器、存储器、输入设备、输出设备

部件组合关系
- 运算器+控制器 = CPU
- CPU + 主存储器 = 主机
- 输入设备 + 输出设备 + 外存 = 外部设备

### 核心思想
该体系结构的核心思想为：**存储程序** + **程序控制**
- 存储程序：程序和数据一样，用二进制形式预先存入存储器
- 程序控制：计算机由控制器根据PC（程序计数器）自动地、一条一条的取出指令并执行，遇到跳转才改变顺序
- 答题模板：程序和数据以二进制形式存于存储器中，计算机自动按顺序逐条去除指令并执行

## 主要性能指标
### 核心公式
```
CPU执行时间 = 指令数 x CPI x 时钟周期
		   = （指令数 x CPI）/ 主频
```
- 时钟周期：1 / 主频（主要单位换算关系：$$1 \text{ MHz} = 10^6 \text{ Hz} = 1,000,000 \text{ Hz}$$$$1 \text{ GHz} = 10^9 \text{ Hz} = 1,000,000,000 \text{ Hz}$$ ）
- `CPI`（Cycle Per Instruction）：每条指令执行所需的平均时钟周期数
- 解题思路：先把“总时钟周期数 = 指令数 x CPI”凑出来，再乘以周期或者除以主频
