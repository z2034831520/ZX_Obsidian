# 个人图片生成风格卡

> [!summary] 核心定位
> 为知识笔记生成一套**理性而温和、简洁、舒缓、长期耐看**的抽象配图。以克制留白、精确秩序和柔和材质营造高级感，不模仿任何公司的具体广告、标志或品牌资产。

## 一、视觉规范

| 项目 | 固定规则 |
|---|---|
| 用途 | 知识笔记头图与章节配图 |
| 画幅 | 16:9 横图 |
| 表达方式 | 用抽象几何关系隐喻知识概念，不做纯装饰 |
| 构图 | 非对称布局；主体位于左侧或右侧三分区，避免机械居中 |
| 留白 | 画面约 45%～60% 保持低信息密度 |
| 形状 | 圆角平面、细线、弧线、少量圆点 |
| 空间 | 平面为主，仅用轻微层叠、柔和阴影和极弱渐变 |
| 材质 | 哑光、柔软、低反射；边缘干净但不锐利 |
| 文字 | 图片内不出现标题、字母、数字、标签或水印 |
| 人物与品牌 | 不出现人物、Logo、商标和可识别品牌产品 |

### 固定色彩

| 角色 | 色值 | 建议占比 |
|---|---|---|
| 暖白背景 | `#F7F5F0` | 70%～85% |
| 柔灰层次 | `#D9DDE2` | 10%～20% |
| 雾蓝识别色 | `#7E9AAF` | 5%～10% |
| 深雾蓝细线 | `#607887` | 少量 |
| 主题辅助色 | 每张最多一种 | 不超过 5% |

主题辅助色默认不使用。需要区分类别时，从以下颜色中只选择一种：

- 鼠尾草绿 `#A8B5A2`
- 柔沙色 `#C9B89D`
- 灰粉色 `#C2A5A7`

## 二、四个可变参数

| 变量 | 填写内容 | 示例 |
|---|---|---|
| `{笔记主题}` | 本篇笔记讨论什么 | FreeRTOS任务调度 |
| `{核心关系}` | 概念之间如何作用 | 多任务在时间轴上轮换与协作 |
| `{主题辅助色}` | 默认填写“不增加辅助色” | 使用极少量鼠尾草绿 |
| `{主体隐喻}` | 用什么几何关系表达主题 | 数个错层圆角平面由一条细弧线连接 |

推荐优先使用的核心关系词：连接、分层、循环、聚合、平衡、成长、分流、同步、反馈、边界。

## 三、固定主提示词

复制下方提示词，只替换四个花括号变量：

```text
为知识笔记《{笔记主题}》创作一张 16:9 横向抽象配图。

概念表达：通过“{主体隐喻}”隐喻“{核心关系}”。几何关系必须与主题存在可解释的联系，不能只是随机装饰。

视觉语言：理性而温和，简洁、舒缓、克制、长期耐看。使用暖白背景 #F7F5F0、柔灰 #D9DDE2 和固定的低饱和雾蓝 #7E9AAF；{主题辅助色}，辅助色占比不得超过画面的 5%。

构图：采用非对称布局，主体位于左侧或右侧三分区，保留约 45%～60% 的安静留白。使用圆角平面、纤细弧线、干净细线和少量圆点。画面以平面设计为主，只加入轻微层叠、极柔和的漫射阴影和几乎不可察觉的渐变。

材质与光线：哑光、柔软、低反射，柔和自然光，低对比度，边缘清晰但不锋利。整体像经过精确排版的现代编辑设计，而不是科技广告。

图片中不得出现任何文字、字母、数字、人物、Logo、商标、水印或可识别品牌产品。
```

## 四、负面约束词

将下列内容附在提示词末尾，或作为模型的 Negative Prompt：

```text
避免：霓虹色，蓝紫强渐变，高饱和撞色，纯黑背景，赛博朋克，复杂电路纹理，发光玻璃球，镜面金属，镀铬材质，强烈光晕，夸张悬浮，深重阴影，强对比，过度锐化，复杂背景，拥挤构图，随机装饰，廉价科技海报，空洞企业图库风格，卡通表情，人物，手，文字，字母，数字，Logo，商标，水印。
```

## 五、变量填写模板

```text
笔记主题：
核心关系：
主题辅助色：不增加辅助色
主体隐喻：
```

选择主体隐喻时，先把主题翻译成关系：

- **连接**：分离的圆角面片由一条细线连接。
- **分层**：大小不同的半透明面片轻微错层。
- **循环**：不完全闭合的柔和弧线围绕少量圆点。
- **聚合**：多个小圆点沿细线汇入一个圆角平面。
- **平衡**：两个不同体量的面片在留白中形成视觉均衡。
- **成长**：由小到大的圆角面片沿缓慢曲线展开。
- **同步**：多个平行弧线在同一节点对齐。
- **反馈**：一条细弧线从主体延伸后柔和回返。

## 六、首轮验证

分别为以下主题填写变量，每个主题生成 3 张候选图：

| 主题 | 推荐核心关系 | 推荐主体隐喻 |
|---|---|---|
| 嵌入式硬件 | 连接与边界 | 数个圆角模块通过细线连接，外围留出明确边界 |
| FreeRTOS | 分流、同步与循环 | 错层面片沿弧形时间轨迹轮换，在少量节点重新对齐 |
| Python 学习 | 分层与成长 | 由小到大的圆角面片沿缓慢上升曲线展开 |
| 阅读思考 | 聚合与反馈 | 分散圆点汇入一个安静的圆角平面，再由细弧线回返 |

### 验收清单

- [ ] 不看标题也能判断所有图片属于同一视觉系列
- [ ] 每张图的几何关系都能解释其主题
- [ ] 暖白、柔灰和雾蓝保持稳定
- [ ] 留白充足，缩小为笔记头图后主体仍然清楚
- [ ] 没有霓虹、强光、玻璃球、镜面金属或廉价科技感
- [ ] 没有文字、人物、Logo、水印和无意义装饰
- [ ] 连续观看时舒缓耐看，而不是追求单张图片的强烈冲击

## 七、使用原则

1. 每次只替换四个变量，不重写固定视觉规则。
2. 第一次生成 3 张候选图，选择概念最准确的一张继续微调。
3. 微调时只改变一个变量，例如主体大小、留白比例或辅助色。
4. 如果图片“漂亮但不像主题”，优先重写 `{核心关系}` 和 `{主体隐喻}`。
5. 如果图片出现廉价科技感，删除新增形容词并强化负面约束，不增加更多特效。
