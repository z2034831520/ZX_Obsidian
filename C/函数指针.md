## 简介
C语言中所有变量都有一个内存地址，函数也有对应的地址，有地址就意味着我们可以通过指针来访问它。函数指针也就应运而生，其是一种专门存放“函数内存地址”的指针，通过它我们可以在程序运行时动态的决定需要调用的函数

## 语法声明
函数指针的语法如下
```c
// 声明一个函数指针变量，名字叫 ptr
int (*ptr)(int, int);
```
- `(*ptr)`：表示`ptr`是一个指针（这里的括号不能缺失，否则就变成了返回指针的函数）
- `int, int`：表示该指针指向的函数，必须接收两个`int`类型的参数
- 最前面的`int`表示函数的返回值必须要是`int`类型

## 代码示例
```c
#include <stdio.h>

// 1. 定义一个符合特征的普通函数
int add(int a, int b) {
    return a + b;
}

int main() {
    // 2. 声明函数指针，并赋值为 add 函数的地址
    int (*calc_ptr)(int, int) = add; 
    
    // 3. 通过指针调用函数
    int result = calc_ptr(10, 5); 
    
    printf("Result: %d\n", result); // 输出 15
    return 0;
}
```

## 作用

我们之所以需要使用指针去调用函数主要是因为函数指针赋予了C语言运行时多态的能力，例如在进行单片机的逻辑开发时，我们可以在回调函数中传入一个函数指针作为参数，这样就能够控制在中断发生时调用指定的函数

由于指针函数的存在我们可以在C语言中去模拟面向对象
```c
// 定义一个传感器的“类”
struct Sensor {
    int id;
    int data;
    // 函数指针充当“成员方法”
    void (*init)(void);
    int  (*read_value)(void);
};
```
